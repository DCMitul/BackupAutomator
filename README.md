Open-source lightweight tool to help you backup your most important files in a easy-to-use way.

## About
BackupAutomator started as a simple python-only project that would also improve my quality of life. I always thought other backup apps were either way too heavy or overkill, so I thought why not make a simple one of my own? And that's how this came into existance.

When I started, I didn't want much of this: just a simple CLI which takes inputs, maybe has default values and does some logging. But oh damn I never thougth I would push it this far, especially the GUI part. Starting to work on the GUI was just a random whim of mine; I didn't even know how back-end works.

But on the bright side, this did help me get familiar with both front and back end, so I'll take it as a win.

## Setting Up
Nothing much here, jsut download the exe installer from the releases and run it, taht should do everything

## Getting satrted with the program

PS: Keep in mind the GUI doesn't work unless you have finished the first set up from the CLI.

- Typing 'backupauto' in the command prompt will bring up the CLI of the program.
- The pragram will guide you through the set up then.
- The you would be the main menu, navigation is from the arrow keys.
- All the options are pretty self explanatory and will guide you through if needed.
- ALwyas try to exit from the main menu instead of presing alt+F4.

### Using the GUI

There are two ways to open the GUI-
- One is to open it up from the launch program(there shoudl be a shortcut on either yoru desktop or start menu)
- The other is to type backupautogui in the command prompt.
